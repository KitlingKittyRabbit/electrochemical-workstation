# Display reference files

The prototype targets the Hongxun 35002 3.5-inch SPI display module using an
ST7796S display controller and an XPT2046 resistive-touch controller.

The supplier's PDFs, example archive, and controller datasheets are not
redistributed here because this repository does not have documented permission
to relicense them. Request the following material from the manufacturer or your
supplier:

- the Hongxun 35002 SPI module manual;
- the CL35BC219-40A wiring drawing;
- the ST7796S controller specification and initialization reference;
- the XPT2046 resistive-touch reference.

Use the document revision matching your physical module. A Chinese historical
note is retained in `README.zh-CN.md`; it is not a license grant for the omitted
vendor files.
