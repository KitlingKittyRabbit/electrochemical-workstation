# Contributing

Contributions are welcome. Keep pull requests focused and identify the exact
board, display, firmware, and operating-system revision used for validation.

Do not add vendor archives or datasheets without documented redistribution
permission. Do not commit measurement data unless every contributor has agreed
to its public release and the data license is stated explicitly.

Before submitting changes, compile the Python sources and build the PlatformIO
firmware when the relevant toolchain is available.
